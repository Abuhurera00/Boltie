# Robot model

checked 2026-11-18 through Sketchfab's public API (`/v3/models/{uid}`). Sketchfab downloads always need a login, so nothing here can be fetched by a script.

the user's picks
- S-Bot Lowpoly (5th-Dimension) - store licence, not downloadable, and it carries guns. no
- Michi Bot (v3dartist) - CC BY-NC, non-commercial clashes with MIT, and it's based on someone else's concept. no
- Little Bot Bunny (NEK) - CC BY 4.0, ok legally, based on David Revoy's concept (credit him too). no rig, 35k faces
- PS4 AR Bot (x-eom) - Sony's character. no, whatever the Sketchfab tag says
- Boogie Bot, two uploads - Poppy Playtime / Mob Entertainment character. no

what Grok Bot looks like
- xAI's design post: simple shapes, expressive eyes, readable at sidebar size, motion shows status (idle, thinking, working, waiting, done)
- not a desktop pet and not 3D. so "look like grokbot" means style, not a model to download

good CC BY 4.0 candidates if we ever ship a GLB
- "cute robot" by victory_ - teal ball, glowing pill eyes, tiny feet, 3.3k faces, 1 animation. best match
- "360 Sphere Robot" by mikeramos - white sphere, black visor, floats
- "Magnetbot (Animated)" by mmkh - 5 animations, busier look

first attempt, now dropped
- RobotExpressive.glb from the three.js repo (r170), CC0, 464 KB, 14 clips (Dance, Death, Idle, Jump, No, Punch, Running, Sitting, Standing, ThumbsUp, Walking, WalkJump, Wave, Yes), morphs Angry/Surprised/Sad, 3237 triangles. worked fine, looked wrong
